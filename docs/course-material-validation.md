# 课程资料上传校验与边界

普通资料与视频、ZIP 的字节限额由 `material_max_upload_bytes` 和 `material_large_max_upload_bytes` 控制，默认分别为 100 MiB 和 500 MiB。列表 API 返回这两个值，界面提示和文件选择后的大小预检使用服务端配置。改变限额需同步 Nginx 请求体限额，给 multipart 元数据留出余量；不能只改后端环境变量。

上传前根据扩展名确定限额，并检查实际文件大小，再执行格式校验；类型判断不信任浏览器声明的 Content-Type。文件存放在私有资料存储中，下载再次校验账号、课程权限、发布状态、版本和会话。这些措施对应 [OWASP 文件上传规范](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html) 中的分层校验、权限、私有存储与大小限制要求。

## ZIP 与 PPTX

校验使用 Python 标准库 [zipfile](https://docs.python.org/3.12/library/zipfile.html) 读取目录信息，并核对本地成员头、名称、偏移和压缩数据边界。没有调用成员 `read`、`open`、`extract` 或 `testzip`，不解压、不执行教学资源。

| 限制 | 当前值 |
|---|---:|
| 成员数 | 最多 5000 |
| 中央目录字节数 | 最多 8 MiB，在创建 ZipFile 前检查 |
| 单成员声明展开大小 | 最多 512 MiB |
| 总声明展开大小 | 最多 2 GiB |
| 单成员声明压缩比 | 最多 200 倍 |
| 成员名称长度 | 最多 1024 字符，本地名称最多 4096 字节 |

拒绝绝对路径、`..` 或空路径段、反斜杠、盘符或冒号、控制字符、以空格或点结尾的路径段；拒绝经 Unicode NFKC 和大小写归一后的重复名称、文件与目录冲突、链接、特殊文件、加密成员、数据重叠和被截断的头或目录。支持 Stored、Deflate、BZIP2、LZMA；不支持分卷和 ZIP64。需要使用支持的普通 ZIP 格式重新打包被拒绝的资源。

PPTX 还必须包含大小写准确的 `[Content_Types].xml`、`_rels/.rels`、`ppt/presentation.xml`，且不能包含与 PPTX 格式不匹配的 `vbaProject.bin`。此检查确认包的基础结构；不解析 Office 全部 XML 语义、不校验解压后每个成员的 CRC，也不证明内容无恶意代码。

## PDF 与视频

PDF 检查有效版本头、尾部 `startxref` 与 `%%EOF`、交叉引用位置、基本对象、Root 和 Size。经典 xref 检查分段和条目、目录对象位置与 Catalog 类型；xref stream 检查字典、W、流长度，无 Filter 时检查索引条目数量与数据长度。结构检查最多读取 2 MiB 的 xref 区域、支持最多 100000 个 xref 条目，基本对象查找最多检查文件开头 1 MiB，Catalog 检查最多 64 KiB。部分复杂、增量保存或大型 PDF 可能超出此兼容范围；可用 PDF 软件重新导出后上传。

这不是完整 PDF 解析器：不解码带 Filter 的 xref 数据、不解释页面或 JavaScript、不执行文档内容。加密文档或需要口令才能阅读的资料应由教师先导出为可供学生阅读的版本。MP4、MOV 除签名外检查 ftyp 盒声明长度与基本布局；WebM 和旧 PPT 使用签名检查。视频校验不等同于完整解码或可播放性验收。

当前未接入杀毒扫描或 CDR。若学校要求内容扫描，需要在发布前接入受控扫描服务，并将扫描完成作为发布条件；不得把现有结构检查描述为已经完成 AV/CDR。

## 失败与验证

畸形文件在替换旧对象之前拒绝，旧文件字节、版本、签名下载地址和存储绑定保持可用。格式验证通过后的存储或数据库失败仍保留原绑定，并清理本次候选对象。

大文件先写入随机私有暂存对象，再复制到新的不可复用键；结构校验、摘要与存储复制期间不持有数据库事务。复制完成后短事务按“账号策略锁、当前账号、当前课程、当前资料”的顺序重新核验账号状态、角色、会话与凭据版本、内容负责人、资料状态与版本，再原子写入绑定和审计。期间内容负责人移交或账号撤权会拒绝本次替换，清理新对象并保留旧绑定及字节。旧地址仍受原来的发布、成员和会话检查约束；并发归档本身会使旧地址失效。成功提交后才回收旧文件。意外退出留下的暂存对象纳入现有存储对账与孤儿清理流程。

自动化覆盖签名伪造、缺失 PDF 结束标记或对象、错误 Root 和 xref、ZIP 路径与重复名称、链接、加密、压缩比、展开量、目录分配前限制、截断目录、PPTX 必需成员和视频 ftyp 长度。合法微型经典 PDF 和 xref stream PDF 另经 `pdfinfo` 解析验证，均为一页。测试与日志保存在忽略的 `.runtime/school-verification` 中；这些测试不是生产内容扫描或目标服务器容量证据。

另外在 SQLite 与专用 MySQL 数据库中，通过复制阶段另一事务提交负责人移交、会话撤销、凭据变更、禁用或角色变化，验证最后提交不会复用旧授权；覆盖资料并发归档、版本更新和复制失败。两类数据库均使用独立测试库，未修改学校业务数据库。
