# 班级课程成绩簿

成绩簿属于管理员分配的授课实例（课程、班级、学期）。管理员查看全校，任课教师只管理负责实例，课程内容负责人没有其他班级成绩权限。学生只查看已发布的本人分项、总分和历史归档；转班后本人历史成绩保留。

## 教师使用

1. 进入「课程成绩管理」，选择课程 / 班级 / 学期。首次配置提供平时30%、实验40%、考核30%；一级与各栏目内的二级比例分别必须合计100%。二级分项可添加、删除和修改比例。
2. 分项可以人工录入，或绑定本实例已发布的作业、考试、实验。同一活动不能重复计入不同分项。所有分项归一到百分制，再用Decimal按两级比例计算，最终四舍五入到两位小数。
3. 作业按题目实得分 / 题目满分的总和归一。当前作业题是100分制；考试按所有题的实际分值归一。实验平台已有选定提交时固定使用其公开成绩；普通实验和作业可以选择最高或最新已公开有效分。新的正式实验提交仍在排队、运行、恢复或等待复核时，即使已有旧选定分，也须等待完成或由教师明确复核分项后再发布总评。
4. 缺交不会静默记零，需教师填写原因明确确认，未提交部分才记零，已得部分分数保留。待评分、系统错误、尚未公开成绩仍阻止发布。免修分项只在所属一级栏目内重新分配权重；整个一级栏目免修时不能发布，需要调整配置。
5. 教师可对来源分项或最终总分调分，必须填写原因。未完成分项不能通过总分调分绕过发布门禁。所有修改先进入草稿，学生继续看到原官方版本。
6. 审核完整后填写原因并发布。发布保存当时的栏目比例、学生名单、分项、来源提交ID/评分版本、原总分和人工调整。来源之后重新评分不自动改变官方成绩，重新发布才形成新版本。
7. 归档复制最近完整的已发布版本，形成独立历史记录。存在未发布修改时不能直接归档。旧归档不会被后续改比例、重评分或调分覆盖。已关闭学期与归档实例不能继续修改成绩。

## 导出与并发

教师和管理员按授权范围下载某个发布/归档版本的Excel或CSV；学生仅下载本人的行。导出包含栏目、计算总分、最终总分、调分原因与版本号，Excel字符串和CSV公式前缀均安全处理。响应不允许公共缓存，导出留下审计。

每次配置、录分、调分、发布、归档都携带`expected_revision`。服务端事务内比较修订并锁定成绩簿，过期版本返回409，前端保留未提交表单供核对，不覆盖其他操作。发布还须带上草稿的`expected_preview_hash`；审核后学生名单或来源评分发生变化时返回409，需刷新并重新审核。发布时冻结所读来源及其版本，不将计算结果作为自动变化的官方缓存。

成绩修改、教务名单变更和实验成绩提交采用一致的短事务锁顺序：先取得教务 / 账号共享锁，再读取当前操作者、授课实例、学期、班级及成绩簿，最后锁定名单、栏目、人工分和来源成绩。MySQL使用`FOR UPDATE`当前读并刷新已缓存的对象，避免`REPEATABLE READ`事务在转班、撤权或调分后继续使用旧快照。Docker运行和AI调用阶段不持有这把锁。正式实验提交和总评发布互相串行，后提交的数据不会覆盖已冻结的旧官方版本。

## 接口

- `GET /api/v1/gradebooks/offerings`：本角色授课实例选择项。
- `GET /api/v1/gradebooks/offerings/{id}`：教师配置/草稿/最新官方版本，学生只有本人官方版本。
- `PUT .../{id}/config`、`PATCH .../{id}/entries`、`POST .../{id}/adjustment`：配置、分项、最终总分调整。
- `POST .../{id}/publish`、`POST .../{id}/archive`：创建独立成绩版本，必填原因。
- `GET .../{id}/snapshots`、`GET /api/v1/gradebooks/snapshots/{snapshot_id}`：历史版本与按角色过滤的内容。
- `GET /api/v1/gradebooks/snapshots/{snapshot_id}/export?format=xlsx|csv`：版本导出。

验证使用隔离数据库：`env -u DAI_DATABASE_URL -u DAI_REDIS_URL .runtime/verify-venv/bin/pytest -q backend/tests/automated/test_gradebook.py`。

`backend/tests/automated/test_gradebook_mysql_concurrency.py` 使用两个独立MySQL会话及事件 / 屏障，验证预览后转班、撤权、学期关闭、栏目和分数变化、两次同时发布的CAS、正式提交与总评发布的两种竞争顺序。设置`DAI_TEST_GRADEBOOK_MYSQL_URL`后运行该文件；它只接受管理员专门建立的空`dai_school_gradebook_verify`数据库，结束后删除该测试库中的表，拒绝非空库及其他库名。并发验证强制使用`REPEATABLE READ`。

已在隔离MySQL完成这组真实事务验证；测试中的队列完成成绩为确定性测试证据，不代表真实Docker评测或部署机容量。真实恢复与上线规模仍需在目标服务器验收。
