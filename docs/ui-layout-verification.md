# 三端桌面 UI 排版与布局验收

日期：2026-09-21。基于原有未提交修改增量整改，保留墨松绿/岩灰及现有业务接口。

## 验收结果

- 63 条页面路由、52 个独立页面组件完成逐路由截图检查；管理员与教师复用页面分别访问。
- 1280×800、1440×900、1920×1080 共 189 个页面样本：无整页横向溢出、无页面运行时异常。
- 1366×768 补充 21 个标签页/弹窗状态截图；已显示的弹窗边界均在视口内。
- Playwright：34 项通过，覆盖长标题、多班级、长列表、空态、失败重试、焦点返回、弹窗取消、考试与评分短屏操作，以及三端下拉栏逐页展开与视口边界。
- 前端 lint、101 个测试文件/919 项 Vitest 测试、生产构建通过。
- 31 个页面/组件中的 75 处原生下拉标签已迁移为统一 `DsSelect`；63 条路由在 1280px 宽度重新采集，无运行时异常或整体横向溢出。
- 学生作业 1280×800 实测：编辑器顶部约229px、高300px，自测/提交操作底部约592px。长题干和输出在各自区域滚动。
