# 平台账号与教务业务实施计划

采用本任务用户确认的详细计划，保留现有 Vue/FastAPI/MySQL/Redis 架构。

## 业务契约

- 新学生以学号登录，默认临时密码 tzcaicode，首次强制改密，有效期默认7天。
- 本人仅能修改昵称、界面偏好、本人密码；正式身份和状态由管理员管理。
- 班级、学生、课程多对多；manual > class > self，关闭学期冻结名单但允许教学收尾。
- XLSX：5000行、5MiB、解压50MiB、单表20列；增量预检确认，导入业务原子提交。
- 重置逐人事务，credential_version 防过时任务覆盖，session_version 撤销旧登录。
- 数据库批次为事实源，独立 account-worker；后台准备密码摘要，不阻塞HTTP。
- 学生历史只读本人提交，不恢复课程权限，不泄露未公开成绩或隐藏内容。
- 增量迁移不改变存量密码；90天清理详细任务输入，365天审计和幂等摘要。

## 交付

账号、教务、批次、历史后端；相应管理/个人页面；迁移；worker与部署；测试与操作手册。
原有工作区用户文档改动保持不动。
